# LUXURY PEARL WEDDING — Sophia & Alexander · 19.06.2027

Весільний сайт-запрошення. Відкрийте `index.html` у браузері — сайт працює без збірки.

## Структура
```
index.html        ← головний файл
css/style.css     ← усі стилі
js/main.js        ← анімації, конверт, галерея, таймер, RSVP, календар
images/           ← фото та фони
README.md
```

## Фотографії
Усі фото на сайті — справжні весільні фотографії з Unsplash (ліцензія Unsplash: безкоштовно, у тому числі для комерційних і портфоліо-проєктів, без обов'язкового зазначення авторства). Вони завантажуються з images.unsplash.com при відкритті сайту.
Якщо інтернет недоступний, сайт автоматично показує локальні перлинні зображення з папки `images/` — сторінка ніколи не буде з «порожніми» фото.

Щоб замінити фото на свої: у `index.html` змініть адресу в `src="..."` потрібного `<img>` (або вкажіть `images/ваше-фото.jpg`).

## Що змінити в тексті (index.html)
- Місце, адреса, карта — секція `WEDDING DETAILS` (пошук: `Villa Erba`)
- Історія — секція `LOVE STORY`
- Програма та дрес-код — там само в `WEDDING DETAILS`
- Дата для таймера — `js/main.js`, рядок `WEDDING_DATE`

## Публікація на Netlify
1. Завантажте вміст цієї папки в репозиторій GitHub (index.html — у корені).
2. Netlify → Add new site → Import from GitHub → оберіть репозиторій.
   Build command — порожньо, Publish directory — `/` (корінь).
3. Відповіді RSVP з'являться в Netlify → Site → **Forms → rsvp**
   (форма вже підключена через `data-netlify="true"`).
   Щоб отримувати листи: Forms → Form notifications → Email.
